ANURAG AIRLINK / FAST IMAGE LINK

Direct browser-to-browser image transfer using WebRTC. No cloud file upload. Pairing uses a manual one-time offer/answer exchange.

● Not connected| WebRTC data channel

Both devices need this page open. Create an offer on the sending device, transfer the offer text to the receiving device, then return its answer text to the sender. After pairing, image bytes travel directly between browsers when the network permits.

Speed note: 10 seconds is a target, not a guarantee. Actual speed depends on image size, Wi-Fi/mobile network, browser and whether a direct route can be established. This version uses public STUN servers but no TURN relay, so some networks may block direct connectivity. Use HTTPS or localhost.
